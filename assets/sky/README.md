# Sky and environment

## Kloofendal 43d Clear (Pure Sky)

- Source: https://polyhaven.com/a/kloofendal_43d_clear_puresky
- Author: Greg Zaal
- License: CC0
- Runtime file: \`kloofendal_43d_clear_puresky_1k.hdr\`
- Resolution: 1K HDRI, downloaded automatically by GitHub Actions.

The game uses the HDRI for the sky background and environment reflections. Moving clouds are a lightweight procedural shader effect, so no separate cloud video or animated texture is required.

The game is not calling the Poly Haven API while players are online. GitHub Actions downloads the static 1K file at build time. Poly Haven is credited here in accordance with its API terms.
